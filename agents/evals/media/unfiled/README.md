# Unfiled — real photographs with no slot in the manifest

These came out of the same 2026-08-20 brake session as the filed corpus. Every one is a
genuine workshop photograph and none of them is a manifest slot, so nothing here is loaded by
a scenario. They are kept because the session is not repeatable — the bike went back together
— and because several of them are the raw material for a slot that is still missing.

| File | What it is | Why it is not filed |
|---|---|---|

| `label-part-number-legible-alt.jpg` | A second pad box, code `X0047Y52CR`, readable but with a hard shadow across the top | Alternate `label/part-number-legible.jpg`. The filed one is flat and evenly lit |
