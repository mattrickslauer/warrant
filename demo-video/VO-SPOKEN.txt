Nobody has ever wanted to write the maintenance record. It's the part you do
afterwards — from memory, off a clipboard, once the machine is closed up and
you want to go home.

So sometimes the box gets ticked and the work didn't happen. The trade has a
name for it. Pencil whipping. Aviation regulators call it falsification and
pull your licence for it. It happens anyway, because paper can't tell the
difference. And downstream of that tick is a pump, a locomotive, an aircraft.

Aviation solved this with a logbook and a licensed signature, and it costs more
than most machines are worth. A courier proves a parcel arrived for pennies.
Nobody built the middle.

So this writes the record for me. I describe the job the way I'd describe it to
somebody on their first day, and an agent asks questions until there's nothing
left to interpret.

Then ordinary code reads what that agent wrote, and hands it back. A tick box
with only one option can't record the job going wrong — so it isn't allowed to
compile. Even the agent that wrote the procedure doesn't get the last word.

What the technician gets is one step at a time. Capture. Next. Nothing is typed
in.

And when a step honestly can't be done — the part is wrong, the bolt is
rounded, the machine is still hot — that is an answer this accepts and writes
down. Not a failure to explain away.

That pad is worn to the metal. It doesn't get a warning. It gets a refusal, and
the step doesn't advance.

A second agent only ever doubts. It never sees what the first one decided — its
instructions don't mention the first one exists. Show two people each other's
answers and they agree, and the second opinion stops being one.

We used to tell the first agent what the part number should be. So it reported
reading a label it couldn't actually see — it quoted the answer back at us. Now
it isn't told. It writes down what is in front of it, and ordinary code does
the comparing.
